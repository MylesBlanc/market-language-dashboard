# Core Futures Dashboard

Interactive futures indices and stock filter dashboard.

## Asia indices
- **Nikkei 225 (NKD)**: 25 major Tokyo constituents (`.T` tickers)
- **Hang Seng (HSI)**: 25 major Hong Kong constituents (`.HK` tickers)
- **Straits Times (STI)**: full 30 Singapore constituents (`.SI` tickers)

Select Linked Index or click an Asia card to filter. International tickers open Yahoo Finance.

## Data
Live delayed quotes via Yahoo Finance (CORS proxies). Refreshes periodically.

Not financial advice.
