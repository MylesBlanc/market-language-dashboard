# Core Futures Dashboard

Interactive futures indices + stock filter with relative-strength shortlist.

## Asia
- **Hang Seng (HSI)**: near-full constituent coverage (~75 major/listed names, `.HK`)
- **Straits Times (STI)**: full 30 constituents (`.SI`)
- Nikkei removed by request

## Shortlist
Top 20 ranked by RS + 1D + 5D trend + liquidity. Links to News and Valuation/chart.

## Daily email
A Grok automation runs **every day at 09:00 Asia/Hong_Kong** and emails an index snapshot + top-20 shortlist (email notification only).

## Data
Delayed Yahoo Finance via public CORS proxies. Not financial advice.
