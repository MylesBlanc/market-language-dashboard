How to use this dashboard
The eleven futures macros (NQ, ES, YM, RTY, NKD, CL, GC, 6E, 6J, ZN, ZB) form the core “language” of the market. Click any macro card to highlight it as the reference for relative-strength ranking. Use the filter panel to surface stocks that historically move with a chosen regime or linked macro. Click any ticker to open its Finviz chart. Live quotes from Yahoo Finance (delayed) via free CORS proxies. No API key required. Refreshes every 60 s. RS = stock % − linked macro %.
