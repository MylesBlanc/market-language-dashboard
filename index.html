How to use this dashboard
The ten futures macros (NQ, ES, YM, RTY, CL, GC, 6E, 6J, ZN, ZB) form the core “language” of the market. Click any macro card to highlight it as the reference for relative-strength ranking. Use the filter panel to surface stocks that historically move with a chosen regime or linked macro. Live quotes from Yahoo Finance (delayed) via free CORS proxies (proxy.cors.dev + allorigins fallback). No API key required. Refreshes every 60 s. RS = stock % − linked macro %.
